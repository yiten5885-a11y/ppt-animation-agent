# 模块 F：插图系统

> 阅读约定：本模块讲做法，不讲概念。凡是提到平台规则、价格、额度、版本兼容性而没有把握的，一律写“需核实”，不编数字。凡是写到动画库的方法名，只保留名字，不抄参数、不抄代码。插图分三条路：程序画图、图库找图、AI 生图，选哪一条先看这一页要讲什么，不要先定图再凑内容。

## 第一节：插图三条路——先选路，再动手

| 路 | 用来画什么 | 要不要接 API | 什么时候用 |
|---|---|---|---|
| 程序画图 | 结构示意图、流程图、对比图、时间线、数据图 | 不用 | 首选。能画出来的图一律程序画，最准、最稳、不依赖外部服务 |
| 图库找图 | 照片、场景图、人物图 | 要联网，免费 key | 讲真实场景、真实人物、真实地点时用；抽象概念不要用照片硬凑 |
| AI 生图 | 封面图、装饰图、风格化插画 | 要接 API 按张计费，或本地跑模型 | 封面与装饰用；正文讲理的页面不要用 AI 图代替示意图 |

三条路的优先级：程序画图 ＞ 图库找图 ＞ AI 生图。能画出来的不找图，能找图的不要现生。AI 生图的图只做封面与装饰，不做讲理的主图——AI 图画不准结构，节点数、箭头方向、公式符号都可能画错。

## 第二节：每页配图规则——纯文字页不许交付

- **内容页至少 1 个视觉元素：** 每一页有正文内容的页面，至少有 1 个视觉元素。视觉元素指四种之一：图片（p:pic）、原生图表（chart）、形状示意图组（三个以上形状按逻辑连起来的图）、视频或 GIF。纯文字的页面不许交付。
- **封面必须有图：** 封面至少有 1 个视觉元素，几何装饰、示意图、照片、AI 图都可以。封面留白不许超过一半。
- **章节页有图：** 每个章节开头页配一张本章主图（本章核心结构的示意图，或一张点题的图）。
- **一页只讲一个图：** 一页最多 1 张主图；主图讲什么，标题就写什么，标题与图对不上就改标题，不要改图凑标题。
- **图与文比例：** 讲理的页面图占页面三分之一到一半，文字只留要点；图是主角，文字是解说，不要反过来。
- **图先定再排版：** 排版式之前先定每页配什么图（见第三节图谱），图定了再进模块 C 排版式。版式里没有留图的位置，图就没地方放。

## 第三节：结构示意图谱——这八种图覆盖大多数讲义

| 图 | 讲什么 | 画法要点 |
|---|---|---|
| 链表图 | 节点、指针、头尾 | 每个节点一个圆角矩形，里面写值；节点之间用箭头连；头指针单独画一个箭头指第一个节点；空指针画一个斜杠框 |
| 栈图 | 后进先出、压栈出栈 | 竖着叠的方框，顶上标 top 指针；入栈画一个箭头从上往下进，出栈画一个箭头从上往下出；栈满栈空各画一种状态 |
| 队列图 | 先进先出、队头队尾 | 横着排的方框，左端标 front、右端标 rear；循环队列画成环形，rear 绕回 front；假溢出画一个被占用的格子 |
| 树图 | 层次、父子、遍历 | 根在上、孩子在下，父子之间用直线连；遍历顺序在节点旁标数字；空子树画一个小方框写空 |
| 关系图 | 图、边、连通、最短路径 | 节点画圆，边画直线或箭头，边上标权重；最短路径那条边加粗、换主色 |
| 流程图 | 步骤、判断、循环 | 开始结束用椭圆，步骤用矩形，判断用菱形，箭头标“是/否”；循环画回箭头，不要画成交叉线 |
| 对比图 | 两种方案的差别 | 左右两栏或上下两栏，同一维度对齐写，差别那一行加粗或标红；不要三栏以上 |
| 时间线 | 先后顺序、发展阶段 | 横向一条线，节点按时间排，当前节点放大，未到节点变淡 |

图谱以外的图，先问三个问题再画：这一页要讲的核心关系是什么（先后、包含、对比、因果）、用哪种图最能讲清、图上有几个元素；元素超过 12 个先拆成两页，不要挤在一页上。

## 第四节：程序画图做法——形状拼，不要贴图

- **用什么画：** python-pptx 原生形状（矩形、圆角矩形、椭圆、箭头、连线、菱形），不用图片文件。形状的名字只保留英文名，不抄参数。
- **画法步骤：** 先定画布区（图在页面上的位置与大小）→ 按图谱摆形状 → 形状之间连箭头或直线 → 每个形状里写字（值、名字、编号）→ 按底座第 4 节上色（主色画主线，辅色画次要元素）→ 渲染看一遍，字有没有溢出、线有没有交叉。
- **箭头规则：** 指针、方向、流程都用箭头；箭头只画一种样式，全 deck 统一；箭头不要穿过文字框。
- **标注规则：** 每个图配一行图注，写清这张图在讲什么；图注放在图下方，字号比正文小两号。
- **检查点：** 画完先在放映尺寸下看一遍：形状对齐了没有、字有没有被形状边框切掉、箭头指的节点对不对。有一项不过就回本节重画，不要带着错图往下走。

## 第五节：数据图规则——每份讲义至少 1 张数据图

- **至少 1 张：** 每份讲义至少有 1 张数据图（折线、柱状、饼图、散点），用 PPT 原生图表做，不要截图贴图。
- **选型：** 看趋势用折线，看对比用柱状，看占比用饼图，看分布用散点。一种数据只用一种图，不要一页放两种图。
- **系列数：** 一张图最多 4 条系列，超过 4 条先拆数据或换表。
- **颜色：** 按底座第 4 节三色法，图表颜色不超过五种；同一系列全 deck 用同一颜色。
- **数字标签：** 关键数据点标数字，标签不许遮住线条；坐标轴单位写清，不要让听众猜单位。
- **图表动画：** 图表按数据顺序生长，折线图从左端向右端延长画出（见模块 D 第六节 6.2），数字标签最后出现。

## 第六节：封面与装饰图——几何装饰首选，AI 图次选

- **几何装饰首选：** 封面用形状拼贴做装饰（色块、线条、角标、主色大字），不用联网、不用花钱、最稳。装饰只用底座第 4 节的主色与辅色，全 deck 只用一种装饰样式。
- **AI 生图次选：** 想要照片感或插画感的封面，再走 AI 生图。生图要接 API 按张计费，或本地跑模型（见第七节）。提示词写清四件事：主体、风格、配色、比例；生出来的图先看一遍再放进 PPT，画错结构、画错文字的图不用。
- **不许留白过半：** 封面留白不许超过一半；留白多了先加装饰元素，不要加字凑数。
- **图与标题不抢：** 封面图放一侧、标题放另一侧；图上有字的地方不许再压标题，标题要落在纯色区。
- **结尾页同理：** 结尾页配一张收束图（本课主图的小版本，或一张点题图），不要只留一句“谢谢”。

## 第七节：图库与 AI 生图取用规则——许可先确认，来源写清楚

- **图库找图：** Unsplash（https://unsplash.com）、Pexels（https://www.pexels.com），免费图库，商用许可见各站许可页。取图要联网；API 方式取图要申请免费 key，key 的申请入口与免费额度以各站官方页面为准（需核实）。
- **AI 生图：** 走 API 按张计费（模型、价格、额度以服务商官方页面为准，需核实）；或本地跑模型，不用接外部 API。本地模型走 Mac mini 部署（本包用户自有设备，Qwen-Image 部署状态见底座第 6 节，部署完成前不要承诺本地生图能用）。
- **许可红线：** 图片先确认许可再用，来源不明的不用，许可不清的先问用户；水印图、带版权标记的图不用。
- **尺寸规则：** 图片进包前先压到合适尺寸（封面图不小于 1600 像素宽，内容图不小于 800 像素宽），不要把几 MB 的原图直接塞进 PPT。
- **来源写进交付说明：** 每张图的来源、许可、大小写进模块 E 的素材清单，来源不明不许交付。

## 第八节：本模块自查清单

- [ ] 每一页内容页至少有 1 个视觉元素（图片、原生图表、形状示意图组、视频或 GIF 之一），纯文字页为零。
- [ ] 封面有图，留白不超过一半；章节页有本章主图；结尾页有收束图。
- [ ] 结构示意图按第三节图谱画，节点、箭头、标注都对得上讲稿，没有画错结构。
- [ ] 图注齐全：每张图下方有一行图注，写清这张图在讲什么。
- [ ] 数据图是 PPT 原生图表，不是一张截图；系列数不超过 4 条，颜色不超过五种。
- [ ] 图片许可都确认过，来源写进交付说明；图片尺寸压过，没有几 MB 的原图塞进包里。
- [ ] 渲染看过一遍：形状对齐、字没溢出、线没交叉、图没变形。
